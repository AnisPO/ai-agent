# AI Expense Agent

**Помощник по личным расходам** — ИИ-агент, который помогает вести учёт трат и анализировать бюджет.

## Назначение

Агент принимает от пользователя информацию о расходах на естественном языке, сохраняет их, распределяет по категориям и показывает сводки за период. Проект разрабатывается на языке **Python**.

## Планируемые возможности

- Добавление расходов с указанием суммы, категории и даты.
- Автоматическое распределение расходов по категориям (продукты, транспорт, развлечения и т.д.).
- Показ суммы расходов за выбранный период (день, неделя, месяц).
- Просмотр истории расходов и фильтрация по категориям.
- Экспорт отчёта о расходах в файл `CSV`.

## Примеры запросов пользователя

1. **Запрос:** «Потратил 500 рублей на продукты вчера».

   **Ожидаемый результат:** агент добавляет расход на 500 ₽ в категорию «Продукты» с датой вчерашнего дня и подтверждает сохранение.

3. **Запрос:** «Сколько я потратил на транспорт за последнюю неделю?»

   **Ожидаемый результат:** агент возвращает сумму всех расходов в категории «Транспорт» за последние 7 дней и, при желании, список этих трат.

## Подготовка окружения и запуск

Для запуска приложения необходимо установить Python версии 3.10 или выше.

### 1. Клонирование репозитория

Откройте терминал и выполните команды:

```bash
git clone https://github.com/AnisPO/ai-agent.git
cd ai-agent
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

Для Windows (Git Bash):

```bash
source venv/Scripts/activate
```

Для Windows (PowerShell):

```powershell
venv\Scripts\Activate.ps1
```

Для Linux и macOS:

```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Запуск приложения

```bash
python main.py
```

После запуска появится приветственное сообщение. Для просмотра списка доступных команд введите `help`.

## Команды приложения

Приложение работает через консольный интерфейс. Пользователь вводит команду и необходимые аргументы.

| Команда | Аргументы | Назначение | Пример |
|---|---|---|---|
| `add` | `<сумма> <категория>` | Добавляет новый расход | `add 500 Продукты` |
| `show` | Нет | Показывает все сохранённые расходы | `show` |
| `change` | `<ID> <категория>` | Изменяет категорию расхода с указанным ID | `change 1 Транспорт` |
| `help` | Нет | Выводит справку по командам | `help` |
| `exit` | Нет | Штатно завершает работу приложения | `exit` |

## Проверка качества кода

Для проверки проекта используются `flake8` и `black`.

Команды необходимо выполнять из корневой папки проекта при активированном виртуальном окружении.

### 1. Проверка линтером flake8

```bash
flake8 main.py cli.py agent.py storage.py
```

Команда проверяет исходные файлы приложения на соответствие правилам оформления и наличие потенциальных проблем в коде.

При успешной проверке ошибок не выводится.

### 2. Проверка форматирования black

```bash
black --check main.py cli.py agent.py storage.py
```

Ключ `--check` запускает проверку форматирования без изменения файлов.

Если файлы отформатированы правильно, команда сообщает, что изменений не требуется. Если форматирование отличается от требований `black`, программа покажет соответствующие предупреждения.

### 3. Автоматическое форматирование

Если требуется исправить форматирование исходных файлов, можно выполнить:

```bash
black main.py cli.py agent.py storage.py
```

Эта команда автоматически форматирует указанные файлы.
