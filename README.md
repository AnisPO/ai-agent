# AI Expense Agent

**Помощник по личным расходам** — ИИ-агент, который помогает вести учёт трат и анализировать бюджет.

## Назначение

Агент принимает от пользователя информацию о расходах на естественном языке, сохраняет их, распределяет по категориям и показывает сводки за период. Проект разрабатывается на языке **Python**.

## Планируемые возможности

- Добавление расходов с указанием суммы, категории и даты.
- Автоматическое распределение расходов по категориям (продукты, транспорт, развлечения и т.д.).
- Показ суммы расходов за выбранный период (день, неделя, месяц).
- Просмотр истории расходов и фильтрация по категориям.
- Экспорт отчёта о расходах в файл `CSV`.

## Примеры запросов пользователя

1. **Запрос:** «Потратил 500 рублей на продукты вчера».
   
   **Ожидаемый результат:** агент добавляет расход на 500 ₽ в категорию «Продукты» с датой вчерашнего дня и подтверждает сохранение.

3. **Запрос:** «Сколько я потратил на транспорт за последнюю неделю?»
   
   **Ожидаемый результат:** агент возвращает сумму всех расходов в категории «Транспорт» за последние 7 дней и, при желании, список этих трат.

## Технологии

- Язык: **Python**
- Хранение данных: `SQLite`
